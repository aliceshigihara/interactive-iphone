# interactive-iphone

Este projeto foi desenvolvido com fins de entretenimento, portanto sem fins comerciais.

interactive-phone (ou fablyphone) é um iPhone interativo sem necessidade de autenticação, com exportação/importação JSON para histórias pessoais ou links públicos para o compartilhamento (sujeito a limites de otimização).

### Acesse o site por: [fablyphone.vercel.app](fablyphone.vercel.app) (sujeito a manutenções)

#### Versão atual: v1.0:
- Aplicativos interativos (Instagram, Twitter, Maps...)
- Apps de Mensagens diversificados (Messages, Whatsapp e KakaoTalk)
- Criação de perfis, publicações, voicemails, chamadas fictícias
- Wallet e Bank fictícios para mais imersão
- Narração interativa (Notificações, chamadas e mensagens)
- Exportação/Importação JSON (Você salva .JSON no seu pc, depois envia novamento ao site para restaurar)
- Links públicos para leitores (Limitações de foto ao usar esta opção)
- Reader View para prévia do seu projeto
- Planejamento de História: Não perca sua linha de pensamento, não confunda horas e dias, o site te auxilia com uma tela de planejamento
- Versão Android futuramente
